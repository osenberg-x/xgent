## UI BSN 重构方案 v2 细化（bevy_resvg）
- 用户 review 后指出 SVG 图标应使用 **bevy_resvg** 加载（非 build.rs 光栅化 PNG），据此细化方案
- 调研 bevy_resvg API（v2.5.0, MSRV 1.95）：`SvgPlugin` + `UiSvg("path.svg")` BSN 原生支持 + `SvgColor(Color)` 运行时 tint
- 发现 **currentColor 着色问题**：31 个 SVG 用 `stroke="currentColor"`，usvg 默认解析为黑色，乘法 tint 对黑色无效
- 解决：build.rs 纯文本预处理（`currentColor`→`#ffffff` + 24→48 2x retina），**不做光栅化**，bevy_resvg 运行时加载
- 明确 xui **不依赖 bevy_feathers**，主题系统（ThemeToken/XuiTheme/ThemedBg/ThemedText/ThemedBorder）自建 ~150 行，模式对齐
- 新增 `ThemedIcon(ThemeToken)` 组件 + `update_icon_tints` 系统，主题切换时全量刷新图标 `SvgColor`
- 方案文档从 1110 行扩充至 1734 行：补全亮/暗调色板全量色值、ThemeSystem 完整代码、7 个技术决策、10 期实施步骤含验证标准

## UI BSN 重构方案深度技术 Review（v2.1）
- 对照 Bevy 0.19 源码 + bevy_resvg 2.5 文档 + bevy_feathers 实际实现，逐条验证方案 API 调用与架构设计
- 发现并修正 **6 个严重问题（P0，编译错误或运行时失败）**：
  1. `NodePosition::Absolute` 类型不存在 → 改为 `PositionType::Absolute`（单元变体，无结构体字段）
  2. `update_theme_colors` 中 `q_text.entity(0)` 硬编码 entity → 改为 `(Entity, &ThemedText)` 迭代
  3. build.rs 路径 `../doc/design/icons` 少一级 → `../../doc/design/icons`
  4. **ThemedIcon 与 UiSvg 在不同实体** — bevy_resvg 的 `sync_svg_color_changes` 要求 SvgColor+ImageNode+UiSvg 同实体 → 合并到同一子实体 + `#[require(SvgColor)]`
  5. 缺少 `HierarchyPropagatePlugin::<TextColor, With<ThemedText>>::new(PostUpdate)` 注册 → Propagate 不生效
  6. `ThemedText(pub ThemeToken)` 混淆 bevy_feathers 的 `InheritableThemeTextColor`（父令牌+传播）与 `ThemedText`（子标记）两种角色 → 拆为 `InheritableThemedText` + `ThemedTextColor` + `ThemedText` 标记三组件
- 发现 **4 个中等问题（P1）**：系统顺序无约束（1帧延迟）、build.rs 缺逐文件 rerun-if-changed、Markdown 解析器过简（改用 pulldown-cmark）、bevy_resvg 硬依赖（改为 feature flag）
