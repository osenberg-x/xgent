## V3 UI 方案引入 BSN

- 用户要求分析项目是否使用了 Bevy 0.19 的 BSN feature，并引入到方案中
- **分析结论**：当前项目零 BSN 使用（grep `bsn!`/`bevy_scene::bsn` 无结果），全部 UI spawn 为 imperative `commands.spawn().with_children()` 模式
- Bevy 0.19 的 BSN 验证：`../bevy/crates/bevy_scene/macros/src/bsn/` 存在完整 parser + codegen；`bevy_feathers` 所有 20+ 控件/容器均用 `bsn! ` 构建（button/checkbox/slider/pane/scrollbar 等）；`bevy_scene` 通过 `"bevy_scene"` feature 启用
- BSN adoption 策略：新模块（companion/content_tabs/pend_card）100% BSN；重写 spawn 函数（status_bar/chat_panel/tool_panel/confirm_dialog）全量改 BSN；轻改模块保持 imperative；ECS update 系统不动
- 在方案中新增 0.5 节（BSN 声明式 UI 构建）：说明背景、对比 imperative/BSN 代码、adoption 策略表、编码约定、依赖变更、团队编码规则
