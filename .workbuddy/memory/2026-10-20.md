# 2026-10-20

## UI v8 M2b：密度档位 + hover 量化（Comet change `v8-m2b-density-hover`）

- 新增 `xgent_ui/src/density.rs`（`DensityPlugin`）：`DensityBase` 记录每个 `Node` 的间距基线（padding/margin/row_gap/column_gap 的 Px），`capture_density_bases` 新节点首帧记基线并按当前档写回，`apply_density_on_change` 在 `ThemeHandle` 变化时按「基线 × 系数」重写 → 幂等不累乘、不重建节点。系数 compact=0.75（4px 网格全落整数）。
- `xgent_settings_core::Preferences.density`（`Density` 枚举，serde snake_case，缺省 Comfortable）；`ThemeHandle` 增 `density`，与主题共用 `generation`（`sync_theme_from_config` 同时读 theme/density）。
- 设置面板：语言下方新增密度分段按钮（抽出 `segment_button` 与语言共用），点击即改 `GlobalConfigRes` + 发 `SaveDensityMessage`（不进「保存」通路）。
- `xgent_app/settings_io`：`save_density` 经 CONFIG_WRITE 落盘；`read_global`/`drain_snapshot`/`apply_save_result` 覆盖该键；新增 `request_preferences_on_startup`（Startup）+ `SnapshotResult.preferences_only`，只回填 preferences，**不走面板快照**（否则开机 provider id 为空会把 context_window 冲成缺省）。
- `xgent_daemon/config_store`：读/写白名单各加 `preferences.density`，写只接受 comfortable/compact。
- `kit.rs` hover：`Or<(Changed<Hovered>, Changed<Pressed>)>` 过滤 + `hover_tint_release_system`（`RemovedComponents<Pressed>` 补松手帧）+ 诊断资源 `HoverTintPollStats{visits,releases}`（空闲帧 visits==0）。
- 新增 `crates/xgent_ui/tests/density.rs` 4 项：rail/顶栏、对话面板滚动区、设置卡片三处真实节点的像素断言 + 密度按钮路径。

### 踩到的坑（下次直接省时间）

- **ChatPanelPlugin 在 headless 测试里要 `UiFonts` 资源**，缺了只报 "Resource does not exist"（bevy 的 debug feature 未开，看不到系统名）。同一 App 还要注册 ChatPanel 订阅的消息（Delta/Done/Error/Retry/Steering/Compacted/SessionCleared/Bounded/ToastMessage/ChatInputSubmitted），并加 `MeshPlugin`/`Clipboard`。
- `bevy::clipboard::ClipboardPlugin` 会被 `UiWidgetsPlugins` 之类重复添加，不要再显式 add。
- 基线既有失败（与本次无关，勿当回归）：`file_preview` 7 项、`file_tree_refresh` 5 项（Message not initialized）、`settings_core::paths::daemon_socket_env_override`（Windows 期望 unix 路径）、`daemon::config_store::global_write_lands_inside_the_isolated_dir`（并行写同一临时配置，基线两次复跑均失败）。
- `cargo clean -p <crate>` 偶尔被安全软件占用返回 SIGTERM，重试即可；`cargo` 报 "invalid metadata files" 时就是 target 被写坏，`cargo clean -p` 该 crate 后复跑。
