机制分两层，内层负责"即时打断"，外层负责"不丢消息"。

内层 stream_llm_response — 流式期即时中断 rust 复制 
loop {
    tokio::select! {
        chunk = stream.next() => { // 正常累加 TextDelta }
        steer = steering_rx.recv() => {
            // race 到 steering → 即时 cancel 当前流
            cancel.cancel();
            return StreamOutcome { pending_steering: Some(steer), .. };
        }
    }
}
外层 run_agent_loop — 停止边界补偿轮询 rust 复制 
if outcome.tool_calls.is_empty() {
    if let Ok(steer) = steering_rx.try_recv() {
        req.messages.push(steer.into_message());
        continue;   // 不 break，重新进入内层
    }
    break;
}
  1. 流式期即时中断 — tokio::select! 同时监听 SSE chunk 与 steering channel，steering 到达立即 cancel 当前流并返回 pending_steering。
  2. 停止边界补偿 — 外层在每个 yield 点用 try_recv 复查一次，防止 steer 恰好落在"准备停止"的窗口里被丢弃。
  3. ECS 同步 — steering 期间 UI 侧 conv.push_user 即时上屏并持久化，语义对齐 omp 的 streamAssistantResponse。
