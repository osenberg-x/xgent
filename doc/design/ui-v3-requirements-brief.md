# XGent UI v3 优化 · 需求摘要

> 产出：需求发现分析师（许明需）｜输入：`doc/design/ui-prototype-v2.html`、`doc/design/requirements.md`
> 供：设计系统专家、原型构建师

## 一、五维度定位

| 维度 | 结论 |
|:---|:---|
| **场景 Surface** | 桌面端 AI Code Agent GUI（Bevy 渲染，非浏览器网页）。单窗口多面板：对话流 / 编辑器 / 终端 / 文件树 / 命令面板 / 高危操作确认弹窗。 |
| **受众 Audience** | 个人开发者，日常用 AI 辅助编码，熟悉 VSCode/Cursor，快捷键肌肉记忆已定型；对效率与观感同时有要求，会因界面"像通用暗色皮肤"而低估产品。 |
| **调性 Tone** | 精密 · 克制 · 有呼吸感 · 有体温 · 状态可读。 |
| **品牌 Brand** | 无既有品牌资产，本次需确立。 |
| **规模 Scale** | 单页富交互原型，一套设计令牌，≥6 个可切换状态演示（对话流 / 分屏 / 确认弹窗 / 命令面板 / 工具执行 / 陪伴状态）。 |

## 二、「现代 / 美观 / 简洁」在 XGent 的具体含义

- **现代 = 信息密度可控**。不是元素更多，而是层级更少、留白更准。
- **美观 = 状态即视觉**（数据驱动）。每一处颜色与动效都在传达 agent 真实状态，不存在纯装饰色块。
- **简洁 = 导航收敛**（实用优先）。现原型有 6 层导航：顶栏 / 活动栏 / viewtabs / sv-tabs / ed-tabs / tv-tabs；且 viewtab「编辑器」与「文件预览」实际调用同一个 `toggleSideView('editor')`，属确凿冗余。
- **轻量 = 视觉负重轻**。细边框、低饱和底、动效 ≤200ms，呼应 NF-03「UI 零延迟、动画不阻塞核心流程」。

## 三、品牌上下文建议

**1. 拆开被过载的强调色。** 现原型 `--accent` 与 `--ok` 同为 `#22C55E`，"品牌 / CTA"与"成功状态"语义直接打架，且该绿色同时承担聚焦环、选中态、发送按钮、终端 prompt、diff 新增行。建议：品牌主色转冷电色系（青—靛紫方向），绿色降级为纯语义成功色。既保留科技感，又立刻拉开与 VSCode 绿的距离。

**2. 冷暖分工。** 冷色 = 系统 / 数据 / 工具执行；预留一支暖色**专供陪伴层**（状态徽章、宠物台词）。用户一眼可分辨"这是机器信息"还是"这是伙伴在说话"。

**3. 陪伴层的正确落点（关键约束，勿踩坑）。** `requirements.md` 4.3 明确：虚拟宠物是**独立置顶透明无边框窗口**、优先级 P1（MVP 后迭代）、**支持整体关闭且关闭后不加载不占资源**、**纯情感向不影响功能**。

因此主 GUI **不应内嵌宠物形象**。正确做法是做一个轻量「**陪伴锚点**」——位于状态栏或输入卡旁的 agent 状态徽章，覆盖 idle / 思考中 / 执行工具 / 待确认 / 出错。宠物开启时它是宠物窗口的入口与呼应；宠物关闭时它优雅退化为纯状态指示器，界面不塌陷。这样既补上差异化，又不违反"纯情感向、可开关、不改变 agent 行为"三条硬约束。

## 四、优化目标清单（可检验）

| # | 目标 | 服务支柱 |
|:--|:---|:---|
| 1 | 引入常驻 agent 状态陪伴锚点，覆盖 5 态；宠物关闭时可优雅降级 | 创意陪伴 + 数据驱动 |
| 2 | 导航层级从 6 层收敛至 ≤3 层，消除 viewtabs 与 sv-tabs 的功能重叠 | 实用优先 |
| 3 | 强调色重构：品牌色与语义状态色彻底分离，绿色不再兼任 CTA | 品牌辨识 |
| 4 | 排版分级重做：正文 / 代码 / 元信息三档字号行高明确，对话流留白加大 | 现代观感 |
| 5 | 微交互补全：流式光标、工具卡展开、待确认脉冲、状态过渡，均 ≤200ms 且遵守 `prefers-reduced-motion` | 轻量 + 数据驱动 |
| 6 | 「待确认」提升为界面级信号，而非仅时间线里一个黄点 | 实用优先 |
| 7 | 状态栏升级为运行时仪表：provider / token / 成本 / daemon 连接态 | 数据驱动 + 轻量 |
| 8 | 图标与设计令牌统一成表，为 Bevy 侧实现留可直接映射的令牌清单 | 可扩展 |

## 五、北极星指标

**开发者截一张图发到社群，别人第一眼认得出「这不是 VSCode 皮肤，这是 XGent」——而且这张图本身就说清了 agent 此刻在做什么。**

即：品牌辨识度与状态可读性必须在同一帧内同时成立，且没有任何一个像素是为了好看而牺牲操作效率。
