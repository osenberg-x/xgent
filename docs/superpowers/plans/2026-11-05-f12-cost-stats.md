# F-12 成本统计实现计划

## 约束

- TDD：每个任务先记录 RED（缺失行为导致），再实现到 GREEN。
- 价格 USD / 1M tokens；未定价不显示 0 元。
- 历史扫描后台线程，不写会话 JSONL。
- 所有用户可见字符串走 i18n；不新增第三方依赖。

## 1. 价格与成本（tasks 1.1–1.2）

<!-- comet-task-ref:10a56886-7ef9-4b6e-adbc-0aa6d10051f7 -->

**结果**：settings_core 有可复用 PricingConfig 与成本计算。

- 新 `crates/xgent_settings_core/src/pricing.rs`：`PricingConfig { input_per_million, output_per_million, models: BTreeMap<String, ModelPrice> }`、`ModelPrice`、`price_for(model)`（字段级回落，0/非法视为未设置）、`cost(prompt, completion, model) -> Option<f64>`（有限非负）。
- `GlobalConfig` 增加 `#[serde(default)] pricing`；重导出。
- 测试（RED→GREEN）：默认价、模型覆盖、部分覆盖回落、未定价、负数/NaN、极小额。
- 验证：`cargo test -p xgent_settings_core pricing`。

<!-- comet-task-ref:2099f992-5a82-4978-acfc-29a2395681b3 -->

**结果**：dev-tutorial 有可照抄的 `[pricing]` 示例。

- 在 `docs/dev-tutorial.md` 增加价格配置、按模型覆盖、未定价说明。
- 示例进入 settings_core 解析测试。
- 验证：`cargo test -p xgent_settings_core pricing::tests::toml_example_parses`。

## 2. daemon 与设置面板（tasks 2.1–2.2）

<!-- comet-task-ref:54fee8a9-ec10-4451-9728-bb5c58a5dcf4 -->

**结果**：全局配置可读写默认价并校验。

- `xgent_daemon/src/config_store.rs` 增加 `pricing.input_per_million`/`pricing.output_per_million` 的读与写；接受 JSON number/数字字符串，要求有限且 `0..=10000`。
- 测试（RED→GREEN）：读取、写入落盘、非法值拒绝、范围边界。
- 验证：`cargo test -p xgent_daemon pricing`。

**结果**：设置面板能编辑默认价。

- `settings_panel.rs` 增加“成本”分区与两个小数输入（专用 marker/解析 f64，不复用 u64 NumField）；保存时只写脏键 `pricing.input_per_million`/`pricing.output_per_million`；非法值拒绝并提示字段。
- 快照 tick 时按 `GlobalConfigRes.pricing` 重建输入。
- 测试（RED→GREEN）：解析合法/非法、脏检查、保存 ConfigItem 键、错误文案。
- 验证：`cargo test -p xgent_ui settings_panel`。

## 3. 当前会话与状态栏（tasks 3.1–3.2）

<!-- comet-task-ref:05a42766-88a4-4640-9296-9fe669945e49 -->

**结果**：当前会话统计从消息重算。

- 新 `crates/xgent_ui/src/cost.rs`（或 `cost/mod.rs`）：`CostStats { prompt, completion, cost: Option<f64>, unpriced: bool }`；`recompute(&Conversation, &PricingConfig)` 遍历 Assistant usage/model；无 usage 跳过；恢复会话自然重算。
- Resource `CostStatsRes` + 系统：Conversation/GlobalConfigRes 变化时重算。
- 测试：一轮累计、恢复消息、无 usage、价格切换、未定价。
- 验证：`cargo test -p xgent_ui cost`.

<!-- comet-task-ref:4bd3ad98-824f-44d7-85fa-ef6a866d2c34 -->

- 验证：`cargo test -p xgent_ui status_bar`。
