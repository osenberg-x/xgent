# Plan: MVP-2 3D 首页

执行方式：`autonomous` + `tdd` + `standard` review。代码任务先写失败测试（RED）再实现（GREEN）；G7 spike 是测量探针，不走 RED/GREEN，但必须有可复跑的测量命令与记录。每个任务以 `tasks.md` 的验证为准；本文件不复制 checkbox。

顺序：G7 gate → L1 数据 → S1 视口+点击 → 布局反转 → 集成验收。G7 的 2k/800 都不过时停在 group 1，记录 2D fallback，不进入 3/4。

## 1. G7 性能 spike（gate）

### 1.1 独立 spike
<!-- comet-task-ref:5e5c0500-a7bc-4fcd-af5a-e142625d56a5 -->
- 范围：`crates/xgent_app/examples/g7_spike.rs`；`Camera3d` → `RenderTarget::Image`，2k 同 mesh/material 实体，轨道/固定相机，单灯。
- 依赖：无。
- 验收：`cargo run -p xgent_app --example g7_spike --release` 可启动，输出节点数与一帧日志/截图。

### 1.2 测量 2k/800 与 1080p
<!-- comet-task-ref:a3be7abb-4771-4dd6-9eb8-fb7d53440f23 -->
- 范围：示例支持 `G7_NODES` 与采样窗口；预热后记录 p50/p95/fps；默认 1280×800，另测 1080p。
- 依赖：1.1。
- 验收：Intel UHD 730（gate）与 NVIDIA T400（reference）各跑一次，记录 GPU/驱动/分辨率/帧时间。

### 1.3 go/no-go 结论
<!-- comet-task-ref:6bc19bd5-56a4-4d6b-80e9-29bb43421d1e -->
- 范围：按 2k@60 → 800/关特效@60 → 2D 写结论；失败时明确停在哪里。
- 依赖：1.2。
- 验收：`docs/notes/g7-3d-perf.md` 存在，含数据与下一步。

### 1.4 回写测试基准
<!-- comet-task-ref:75b731d5-8d6a-4ab1-9704-ece56d4c4266 -->
- 范围：把实测机器/分辨率/结论写回 `docs/design/ui-v8-3d-viewport.md` 的测试基准段。
- 依赖：1.3。
- 验收：文档基准与 `docs/notes/g7-3d-perf.md` 一致。
