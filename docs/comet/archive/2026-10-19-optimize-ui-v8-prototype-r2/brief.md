# Outcome

`optimize-ui-v8-prototype-r2`：继续优化 v8 交互原型 `docs/design/ui-prototype-v8.html`，按四块范围补齐「陪伴 / 权限 / 运行态 / 空态」的设计面：① **3D 陪伴主线**——把产品既有的两处陪伴占位（图标轨底部按钮、状态栏段）补齐进原型并升级为「状态感知 + 浮层入口」，另含独立陪伴窗口概念预览与模型 popover 3D 区升级；② **权限与安全交互**——会话级权限模式（询问/自动/全自动）、确认弹窗三档放行粒度、设置「工具与安全」权限矩阵实表；③ **运行态与恢复可视**——同轮并行工具、失败/中断恢复、回合撤销（检查点）、上下文用量与压缩事件卡；④ **空态与历史**——v8 欢迎页、历史面板搜索/分组。

参照「项目设计与需求 + 当前成熟 agent 的功能设计」（Claude Code 权限模式与预批准规则、opencode allow/ask/deny 规则集、检查点恢复共识、项目内 omp 研究），仅取交互模式不复制视觉；保留 XGent 特色（3D 陪伴、陪伴暖色琥珀、轻量陪伴感）。视觉全部沿用 v7-Linear Tokens（ADR-0014），改完在浏览器中可完整走查上述四块。

**只改设计文档产物**（原型 HTML + 任务台账附段），不触碰任何 Rust 代码。

# Decisions

- D-1 权限三档：询问（逐次确认，§5.4 默认行为）/ 自动（只读类自动，等价「按工具提升为 Approved」的会话级快捷）/ 全自动（全部自动，受保护路径仍逐次确认）。会话级覆盖、受保护路径、警示样式为设计先行项，文案显式标注。
- D-2 陪伴驻留点 = rail 底部（对齐产品 `activity_bar` 既有按钮位置与暖色星标），并补齐状态栏陪伴段（对齐 `status_bar`）；点击交互由「开关」升级为「开浮层（含开关）」。
- D-3 状态环 = 暖色动画语义（避免与 st_pending 琥珀撞色的换色歧义）+ 特殊态叠加（等待确认琥珀点/错误红环）。
- D-4 独立窗口 = 概念预览 mock，显式标注 F-15/K-04，非本轮交付。
- D-5 参照仅取模式不抄视觉（延续 round 1 D-4 口径）。
- D-6 撤销 = 回退本回合文件检查点（R3-11 语义），提示「覆盖边界如实说明」（沿用产品既有修复纪律）。
- D-7 历史搜索/分组为设计先行（会话检索依赖 D-04/OQ-07 未决）。
- D-8 不新增 ctl 演示开关（复用既有交互触发）；确有必要时例外并说明。
