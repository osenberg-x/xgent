# 目标

把 3D 首页从「可看、可点」推进到「可键盘查找、选中与双向联动」：用户不离开宇宙就能遍历节点、搜索并飞行定位文件，2D 编辑器的当前文件与 3D 选中态保持一致，Esc 逐级退出而不误中断对话。

# 范围

- 仅覆盖 F-16 的 S2 交互联动，在 `LayoutMode::Universe` 下生效；经典 2D 回退保持 MVP-1 行为。
- **键盘遍历**：`Tab` / `Shift+Tab` 在当前可见节点间按屏幕极角顺序循环（回绕）；选中时相机 target 跟随选中节点，yaw/pitch/dist 不变；文本输入框有焦点时不抢键。
- **搜索飞行**：`/` 打开视口内搜索；按 label/path 子串过滤当前图的 File 节点；`↑` / `↓` 移动结果，`Enter` 选中并把相机飞到该节点（target + dist 调整），不直接打开编辑器；`Esc` 先关闭搜索。
- **2D ↔ 3D 联动**：编辑器活动文件变化时，在图中选中同路径的 File 星体（不移动相机）；图中选中 File 后 `Enter`/双击仍打开同一文件到 2D 编辑器（S1 回归）。文件不在图中时清除 3D 选中。
- **Esc 逐级回退**：搜索打开 → 关闭搜索；编辑器/终端/差异可见 → 回宇宙（保留选中）；宇宙可见且有 3D 选中 → 清除选中；以上都没有且宇宙可见 → 才中断对话。任何一级都不得穿透到对话中断。
- **选中反馈**：悬停 120ms 后显示 label/path tooltip；选中详情卡显示 label、path、节点类型与「Enter 打开」提示（L1 无 LOC 数据，不显示 LOC）。
- S2 的搜索/遍历必须覆盖当前图全部可见节点（2k 档内），不引入新的每帧全量路径分配。

# 非目标

- S3 时空回溯、S4 插件节点、L2 符号/调用边。
- 自由飞行/惯性、第一人称相机、跨项目搜索、搜索历史。
- 3D 内渲染源码或编辑。
- Classic 回退下的 3D 键盘遍历/搜索（空间视图不可见）。
- 悬停 tooltip 中的 LOC（L1 图没有行数数据；不为此读取 2k 文件）。

# 验收示例

- A1 **Tab 遍历不转相机**：宇宙可见且文本输入框无焦点时，连续按 `Tab` 能遍历全部可见节点并回绕；每次仅选中态与相机 target 改变，yaw/pitch/dist 保持不变；`Shift+Tab` 反向。
- A2 **搜索飞行不打开编辑器**：按 `/` 输入文件名片段，`↑`/`↓` 选择，`Enter` 后搜索关闭、选中目标星体且相机飞到它；编辑器未打开。
- A3 **键盘完成找文件→打开**：在 A2 之后再次按 `Enter`，主区切换到 2D 编辑器并打开搜索选中的同一路径。
- A4 **2D→3D 选中同步**：在编辑器中切换活动文件（或从文件抽屉打开文件）后，3D 图选中同路径的 File 星体且相机不移动；图中不存在的文件清除选中。
- A5 **Esc 逐级不穿透**：搜索打开时 Esc 只关搜索；编辑器/终端可见时 Esc 回宇宙并保留选中；宇宙有选中时 Esc 只清选中；只有宇宙无搜索无选中时 Esc 才中断对话。
- A6 **回退隔离**：经典 2D 回退下 `/`、`Tab` 不改变布局或触发 3D 搜索；MVP-1 的对话/编辑器/终端/抽屉/设置/历史行为不回归。
- A7 **选中反馈**：悬停星体 120ms 后出现 label/path tooltip；单击后出现详情卡（label/path/类型/Enter 提示），不遮挡视口拾取，切换选中或清除选中时同步更新/消失。

# Decisions

- Q1：S2 包含悬停 tooltip 与选中详情卡；tooltip 显示 label/path，详情卡显示 label/path/类型/Enter 提示，不显示 LOC。
- Q2：编辑器切换活动文件只同步 3D 选中态，不移动相机。
- Q3：`/` 搜索仅覆盖 File 节点。
